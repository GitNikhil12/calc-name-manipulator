# calc-name-manipulator
Python Fundamentals: Basic Operations & String Manipulation

This repository contains my solutions for the Python programming assignment. The projects focus on handling user input, performing arithmetic calculations, and string concatenation.

📋 Assignment Tasks

1. Simple Arithmetic Calculator
A Python program designed to perform basic mathematical operations.
 • Inputs: Takes two numerical values from the user.
 • Operations: 
   • Addition (+)
   • Subtraction (-)
   • Multiplication (*)
   • Division (/)
 • Output: Displays the result of each operation clearly on the screen.

2. Personalized Name Concatenator
A program that demonstrates how to handle and manipulate strings.
 • Inputs: Prompts the user for their First Name and Last Name.
 • Logic: Concatenates (combines) both inputs to create a Full Name.
 • Output: Prints a personalized greeting message (e.g., "Hello, [Full Name]! Welcome to the Python world!").

🛠️ Tech Stack
 • Language: Python 3.14.2
 • Tools: VS Code / Terminal / Git

🚀 How to Run the Program
  • Make sure you have Python installed on your system.
  • Download the .py files from this repository.
  • Open your terminal or command prompt.
  • Run the following command:
  python assignment.py
